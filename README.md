# Quark

New version: change `"version"` in `package.json` (for example 1.0.1), then open the **Actions** tab,
choose **Build and release** and press **Run workflow**. After a few minutes the new
`Quark-Setup.exe` appears under **Releases**, and installed copies update themselves.

Keep two-factor authentication ON for this GitHub account: whoever controls this repository controls the updates.
Never put passwords or tokens in these files.
